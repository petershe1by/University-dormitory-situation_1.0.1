# 全国高校宿舍查询 · 内测版

这是 [`University-dormitory-situation`](https://github.com/petershe1by/University-dormitory-situation) 的体验优化版本，用于在本仓库进行内测。原仓库与原网页保持不变。

## 本次优化

- 把校名搜索升级为校名、城市、地址和全部生活字段的跨字段检索。
- 修复“1 人间”错误匹配“10/11/12 人间”的问题，并增加 9 人以上筛选。
- 将夜间供电分为“明确不断电、条件供电、明确断电、暂无资料”，避免混合情况被简单归类。
- 修复 1.0.1 中“定时热水”选项不生效的问题。
- 增加常用条件组合、资料完整度提示、不同校名统计、移动端卡片和无障碍键盘操作。
- 增加页面内留言反馈表单，可整理内容并跳转到 GitHub Issue 提交。
- 不清洗或改写原始事实字段，详情中仍展示原始文字，便于核对。

## 本地预览

静态页面通过 `fetch` 读取 JSON，请使用本地 HTTP 服务，不要直接双击 `index.html`：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 检查

安装 Node.js 20 或更高版本后运行：

```bash
npm test
npm run validate:data
```

项目没有第三方运行时依赖，也不需要构建步骤。

## 数据边界

数据来自学生公开分享，可能因校区、楼栋、年级、培养层次和年份不同而变化。当前数据没有逐条来源、采集时间和核验状态，因此只能作为调研线索，不能替代学校官方住宿安排。

“资料完整度”仅表示若干核心字段是否填写，不代表信息的真实性或新鲜度。
